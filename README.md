# AI Data Mapping System (Python)

An AI-driven data mapping system using rule-based logic, ML, and NLP to map source schemas (CSV/Excel/JSON) to a canonical target schema.

## Tech Stack
- Python
- Pandas
- Scikit-learn
- NLP (TF-IDF)
- Rule-based engine

## How to Run
```bash
pip install -r requirements.txt
python src/main.py
